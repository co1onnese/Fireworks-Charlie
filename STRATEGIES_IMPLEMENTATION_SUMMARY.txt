Strategy A: Long-Only
────────────────────────────────────────────────────────────────────
BUY/STRONG_BUY     → Long position  → Return = +actual_return
HOLD/SELL          → No position    → Return = 0%

Example: BUY on +2.5% stock → Portfolio: +2.5%
         SELL on -3.0% stock → Portfolio: 0% (avoided loss)

Risk: 🟢 Low | Volatility: Low | Leverage: None


Strategy B: Long/Short
────────────────────────────────────────────────────────────────────
BUY/STRONG_BUY     → Long position  → Return = +actual_return
SELL/STRONG_SELL   → Short position → Return = -actual_return
HOLD               → No position    → Return = 0%

Example: BUY on +2.5% stock → Portfolio: +2.5%
         SELL on -3.0% stock → Portfolio: +3.0% (short profit!)
         SELL on +2.0% stock → Portfolio: -2.0% (short loss)

Risk: 🟡 Medium | Volatility: Medium | Leverage: None


Strategy C: Weighted (High-Risk)
────────────────────────────────────────────────────────────────────
STRONG_BUY   → 2x long position     → Return = 2 × actual_return
BUY          → 1x long position     → Return = actual_return
HOLD         → No position          → Return = 0%
SELL         → -1x short position   → Return = -actual_return
STRONG_SELL  → -2x short position   → Return = -2 × actual_return

Example: STRONG_BUY on +3.0% stock → Portfolio: +6.0% (2x gain!)
         STRONG_SELL on -3.0% stock → Portfolio: +6.0% (2x short!)
         STRONG_BUY on -2.0% stock → Portfolio: -4.0% (2x loss!)

Risk: 🔴 High | Volatility: High | Leverage: 2x

⚠️  WARNING: Strategy C amplifies both gains AND losses!
